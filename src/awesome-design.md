# Awesome Design System

## Principles
- Minimal, modern, lots of whitespace
- Use shadcn/ui + Tailwind
- Rounded: rounded-2xl, not rounded-md
- Shadows: soft, shadow-xl with blur, never harsh borders
- Typography: font-semibold, tracking-tight for headings
- Colors: Use slate/zinc neutrals + one accent (violet-500)
- No pure black #000, use zinc-950 or slate-900
- Buttons: h-11 px-8 rounded-full, subtle hover scale
- Cards: bg-white/80 backdrop-blur, border border-zinc-200/50

## Inspiration
- Linear app, Stripe, Vercel, Apple
- Avoid: gradients everywhere, purple on purple, too many emojis

## Always
- Use lucide-react icons
- Add subtle motion with react-bits or motion
- Mobile first
