# Impeccable Code & Design Rules

ABSOLUTELY NO:
- No purple gradients on white
- No Inter font everywhere, use Geist / Instrument Serif
- No rounded-3xl + shadow-2xl on everything
- No lorem ipsum, use real copy
- No generic AI illustrations

ALWAYS:
- Use 8px grid, whitespace is luxury
- Max 1 accent color, 60-30-10 rule
- Buttons: 44px height min, font-medium
- Borders: 1px, not 2px. Color: zinc-200, not zinc-300
- Text: text-balance, leading-relaxed
- Empty states must be designed, not "No data"
- Every page needs 1 wow moment (react-bits component)

CODE:
- Use shadcn/ui, never invent own Button
- Use cn() for classes
- No inline styles
